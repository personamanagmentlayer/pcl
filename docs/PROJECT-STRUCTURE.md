# PCL Project Structure

This document describes the organization of the PCL project directory.

## Root Directory (Professional & Clean)

The root directory contains only essential project files:

```
pcl/
├── README.md              # Main project documentation
├── CHANGELOG.md           # Version history
├── CONTRIBUTING.md        # Contribution guidelines
├── QUICKSTART.md          # Quick start guide
├── LICENSE                # Apache 2.0 license
├── LICENSE-DOCS           # Documentation license
├── NOTICE                 # Copyright notices
├── package.json           # NPM package configuration
├── package-lock.json      # Dependency lock file
├── tsconfig.json          # TypeScript configuration
├── vitest.config.ts       # Test configuration
└── .editorconfig          # Editor configuration
```

All project documentation is organized in the `docs/` directory:

## Changes from Previous Structure

### Moved Files

1. **Registry Documentation** → `docs/registry/`
   - `DATABASE-FREE-REGISTRY.md`
   - `REGISTRY-CHEATSHEET.md`
   - `TEST-RESULTS.md`

2. **Detailed Changelogs** → `docs/changelog/`
   - `CHANGELOG-2026-01-18.md`

3. **Example Personas** → `examples/personas/`
   - `test-persona.pcl`

### Benefits of New Structure

✅ **Professional Root** - Only essential files visible at top level
✅ **Better Organization** - Related docs grouped together
✅ **Easy Navigation** - Clear folder hierarchy
✅ **Scalable** - Easy to add new documentation
✅ **Standard** - Follows best practices for open source projects
