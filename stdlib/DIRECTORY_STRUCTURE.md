## File Format

Each skill is stored as either:
- **Directory structure**: `<skill-name>/SKILL.md` (traditional format)
- **Direct file**: `<skill-name>.md` (newer additions)

Both formats follow the same PCL Agent Skills specification with:
- YAML frontmatter
- Core concepts
- Code examples
- Best practices
- Anti-patterns
- Resources
