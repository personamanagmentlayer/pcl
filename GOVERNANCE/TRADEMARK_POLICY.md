## 1. Overview

This document defines the trademark policy for **PCL (Persona Control Language)** and related project names, consistent with the Apache 2.0 license under which the PCL source code is distributed.

**Key Principle**: The PCL source code is licensed under Apache 2.0 (permissive), but the PCL trademarks are owned by IbIFACE and subject to separate usage terms.

## 3. Permitted Uses (No Permission Required)

### 3.1 Fair Use

You **MAY** use PCL trademarks without permission for:

✅ **Factual References**

- "This application uses PCL"
- "Compatible with PCL v1.0"
- "Powered by PCL"

✅ **Attribution**

- "Built with PCL by IbIFACE"
- Link to official website: https://pcl-lang.org

✅ **Educational & Commentary**

- Academic papers: "Analysis of PCL's governance model"
- Blog posts: "Why we chose PCL for AI orchestration"
- Conference talks: "PCL vs. LangChain comparison"

✅ **Community Contributions**

- GitHub issues, pull requests
- Community forum discussions
- Open-source tools that _integrate with_ PCL (e.g., "PCL-Toolkit" helper library)

### 3.2 Badges & Stickers

You **MAY** use these phrases without permission:

- "Built with PCL"
- "Supports PCL"
- "PCL-compatible"

**Badge Example** (permitted):

```markdown
![Built with PCL](https://img.shields.io/badge/Built%20with-PCL-blue)
```

## 4. Prohibited Uses (Requires Written Permission)

### 4.1 Commercial Products

You **MUST NOT** use PCL trademarks for:

❌ **Product Names**

- "PCL Cloud" (without authorization)
- "Enterprise PCL Suite"
- "PCL Pro"
- "[Company] PCL Edition"

❌ **Implying Official Status**

- "Official PCL Tools"
- "Certified PCL Implementation"
- "PCL Approved"

❌ **Modified Distributions**

- Forked projects claiming to be "PCL" (must use different name, e.g., "MyAI-Lang based on PCL")
- Incompatible implementations labeled "PCL"

❌ **Domain Names**

- pcl-enterprise.com (commercial use)
- official-pcl.io (implies endorsement)
- Exception: Community domains like "pcl-community.org" with clear disclaimer

### 4.2 Logo & Branding

❌ **Prohibited Without Permission**:

- Using PCL logo in your product branding
- Creating derivative logos (e.g., PCL logo + your company logo)
- Using PCL trade dress (colors, fonts, style) that creates confusion

✅ **Permitted**:

- Unmodified PCL logo in documentation/presentations with attribution
- "Built with PCL" badge with standard badge artwork

## 5. Special Cases

### 5.1 Open Core Extensions (Authorized)

**IbIFACE MAY grant trademark licenses to**:

- Official PCL Cloud (SaaS offering)
- PCL Enterprise Support
- PCL Certified Training

**These require explicit trademark licensing agreements.**

### 5.2 Community Projects

**Community projects SHOULD use naming conventions:**

- ✅ "PCL-Toolkit" (helper library)
- ✅ "Super-PCL-Linter" (linting tool)
- ✅ "PCL Syntax Highlighter for VS Code"

**Clear attribution required:**

> "This project is a community tool for PCL. PCL is a trademark of IbIFACE. Not officially endorsed by IbIFACE."

### 5.3 Forks & Derivative Works

If you fork PCL and make **incompatible changes**:

- ❌ MUST NOT call it "PCL" or "PCL [Variant]"
- ✅ MUST use different name (e.g., "MyAI-Lang")
- ✅ MAY state: "Based on PCL by IbIFACE"

**Example: Elasticsearch → OpenSearch** (changed name after fork)

## 6. Compliance & Enforcement

### 6.1 Trademark Enforcement

IbIFACE will enforce this policy to:

- **Prevent consumer confusion**
- **Maintain quality standards** (no "PCL" products that violate specifications)
- **Protect community** (prevent trademark squatting)

### 6.2 Violation Response

**Step 1 - Friendly Notice** (most cases)

- Email notification explaining policy
- 30-day cure period to rename/rebrand

**Step 2 - Formal Cease & Desist**

- Legal notice if no response
- Request for public correction

**Step 3 - Legal Action**

- Only for willful infringement or refusal to comply
- Seeks injunction, not damages (unless malicious)

**Goal**: Collaboration, not litigation.

### 6.3 Reporting Violations

To report trademark misuse:

- **Email**: legal@ibiface.com
- **Subject**: "PCL Trademark Issue - [Brief Description]"
- **Include**: URL, screenshot, description of concern

## 9. Trademark FAQs

### Q1: Can I use "PCL" in my company's internal tools?

**A**: ✅ Yes, for internal use, no permission needed.

### Q2: Can I sell "PCL Training" services?

**A**: ⚠️ Contact legal@ibiface.com. May require licensing agreement to ensure quality standards.

### Q3: Can I fork PCL and call it "Better PCL"?

**A**: ❌ No. Must use different name (e.g., "BetterAI-Lang"). May state "based on PCL."

**A**: ⚠️ Contact legal@ibiface.com. Name implies official product. Better: "MyIDE for PCL."

### Q5: Can I use the PCL logo on my website?

**A**: ✅ Yes, in documentation/tutorials with attribution. ❌ No, if it implies endorsement.

### Q6: What if I violate this policy accidentally?

**A**: Contact legal@ibiface.com immediately. Most issues resolved amicably with renaming/clarification.
